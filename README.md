# PokeFusion

A modern, responsive Pokémon fusion generator MVP.

## MVP
- Search and select two Pokémon from the PokéAPI catalog
- Instant fusion naming and visual result
- Random fusion
- Download result as PNG
- Shareable fusion URL structure (`/pokemon-fusion/a-b`)
- Responsive mobile-first UI
- SEO-ready metadata and expansion points for programmatic fusion pages

## Development

```bash
npm install
npm run dev
npm run build
```

The app uses PokéAPI for the Pokémon catalog and official-artwork sprites hosted by the PokeAPI sprites repository.
